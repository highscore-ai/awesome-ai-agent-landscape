# Gemini API

[Official Gemini API model catalogue](https://ai.google.dev/gemini-api/docs/models)

> API pricing in USD. Verified 25 August 2026.

## API access

| API tier | Monthly spend cap | Spend rate limit |
|---|---:|---:|
| Free | N/A | N/A |
| Tier 1 | US$250 | US$10 per rolling 10 minutes |
| Tier 2 | US$2,000 | US$50 per rolling 10 minutes |
| Tier 3 | US$20,000–100,000 | US$200 per rolling 10 minutes |

Gemini Developer API has free and paid tiers. Exact RPM, TPM, and daily request limits vary by model and are shown in Google AI Studio for the account.

## Current model access

- Stable releases use versioned model IDs, such as `gemini-3.6-flash`.
- Preview releases can have more restrictive limits and are subject to deprecation.
- Gemini 3.7 Flash introductory pricing ends 31 December 2026; its announced standard price from 1 January 2027 is US$1.50 input and US$7.50 output per 1M tokens.
