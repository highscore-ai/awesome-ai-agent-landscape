## Plan comparison

ChatGPT Work is included with ChatGPT Free, Go, Plus, Pro, Business, Edu, and Enterprise. Its usage is shared with Codex.

| Plan | Price | Work access | Five-hour local-message allowance | After the included allowance |
|---|---:|---|---|---|
| Free | US$0/month | Included | OpenAI does not publish a numeric Work range for Free. | Wait for the reset shown in Usage. |
| Go | US$8/month | Included | OpenAI does not publish a numeric Work range for Go. | Wait for the reset shown in Usage. |
| Plus | US$20/month | Included | Sol: **10–100** · Terra: **25–200** · Luna: **250–2,000** | Eligible users can buy ChatGPT credits. |
| Pro — 5× | US$100/month | Included | Sol: **50–500** · Terra: **125–1,000** · Luna: **1,250–10,000** | Eligible users can buy ChatGPT credits. |
| Pro — 20× | US$200/month | Included | Sol: **200–2,000** · Terra: **500–4,000** · Luna: **5,000–40,000** | Eligible users can buy ChatGPT credits. |
| Business | US$20/user/month annually, or US$25 monthly | Included | Sol: **10–100** · Terra: **25–200** · Luna: **250–2,000** | Workspace credits can extend use when flexible pricing is enabled. |
| Edu / Enterprise | Contract pricing | Included | Flexible-pricing workspaces: no fixed rate limit; usage scales with credits. Without flexible pricing: usually the Plus per-seat range. | Workspace credits where enabled. |

The ranges are estimates of **local messages per rolling five-hour window**. Cloud chats use GPT-5.6 Sol and can use more allowance than local messages. Additional weekly limits may apply.

## How Work usage is counted

| Model | Input | Cached input | Output |
|---|---:|---:|---:|
| GPT-5.6 Sol | 100 credits / 1M tokens | 10 credits / 1M tokens | 500 credits / 1M tokens |
| GPT-5.6 Terra | 50 credits / 1M tokens | 5 credits / 1M tokens | 300 credits / 1M tokens |
| GPT-5.6 Luna | 5 credits / 1M tokens | 0.5 credits / 1M tokens | 30 credits / 1M tokens |

- A GPT-5.6 Work or Codex message averages approximately **5–30 credits**, but comparable-looking tasks can vary substantially by context, reasoning, tool use, retrieval, and caching.
- Work and Codex use the same allowance, credits, and limits. Usage also shares the agentic pool with ChatGPT for Excel where that feature is available.
- Fast mode uses **2.5×** the standard credit rate for GPT-5.6 and GPT-5.5.
- Image generations count against the same general allowance and typically consume it **3–5×** faster than similar turns without image generation.

## When usage runs out

- An active turn may finish, subject to fair-use limits.
- Plus and Pro users can purchase credits without changing their plan.
- Business, Edu, and Enterprise workspaces can use workspace credits when flexible pricing is enabled.
- Any user can run additional local tasks using an API key; those calls use separate pay-as-you-go API pricing.
