## Plan comparison

| Plan | Price | Codex access | Five-hour local-message allowance | After the included allowance |
|---|---:|---|---|---|
| Free | US$0/month | Included for quick tasks | OpenAI does not publish a numeric Codex range for Free. | Wait for the reset shown in Usage. |
| Go | US$8/month | Included for lightweight tasks | OpenAI does not publish a numeric Codex range for Go. | Wait for the reset shown in Usage. |
| Plus | US$20/month | Web, desktop app, CLI, IDE extension, iOS, and cloud integrations | Sol: **10–100** · Terra: **25–200** · Luna: **250–2,000** | Eligible users can buy ChatGPT credits. |
| Pro — 5× | US$100/month | Everything in Plus; GPT-5.3-Codex-Spark preview | Sol: **50–500** · Terra: **125–1,000** · Luna: **1,250–10,000** | Eligible users can buy ChatGPT credits. |
| Pro — 20× | US$200/month | Everything in Plus; GPT-5.3-Codex-Spark preview | Sol: **200–2,000** · Terra: **500–4,000** · Luna: **5,000–40,000** | Eligible users can buy ChatGPT credits. |
| Business — Standard | US$20/user/month annually, or US$25 monthly | Included | Sol: **10–100** · Terra: **25–200** · Luna: **250–2,000** | Workspace credits can extend use when flexible pricing is enabled. |
| Business — Premium | US$100/user/month annually, or US$125 monthly | Included | **5×** Standard-seat usage; no 5-hour usage limit. | Workspace credits can extend use when flexible pricing is enabled. |

The ranges are estimates of **local messages per rolling five-hour window**. Cloud chats use GPT-5.6 Sol and can use more allowance than local messages. Additional weekly limits may apply.

## Usage and credits

| Model | Input | Cached input | Output |
|---|---:|---:|---:|
| GPT-5.6 Sol | 100 credits / 1M tokens | 10 credits / 1M tokens | 500 credits / 1M tokens |
| GPT-5.6 Terra | 50 credits / 1M tokens | 5 credits / 1M tokens | 300 credits / 1M tokens |
| GPT-5.6 Luna | 5 credits / 1M tokens | 0.5 credits / 1M tokens | 30 credits / 1M tokens |

- A GPT-5.6 Codex message averages approximately **5–30 credits**. Actual consumption depends on model, task size, context, reasoning, tool use, retrieval, and caching.
- Codex and ChatGPT Work share the same agentic allowance. ChatGPT for Excel also shares the pool where it is available.
- Fast mode consumes **2.5×** the standard credit rate for GPT-5.6 and GPT-5.5.
- Image generations use the included allowance roughly **3–5×** faster than comparable turns without image generation.
- Purchased credits expire 12 months after purchase; they are non-refundable and non-transferable.

## When the allowance is used

- An active turn may finish, subject to fair-use limits.
- Plus and Pro users can add credits, use a banked reset where offered, upgrade, or wait for reset.
- Business, Edu, and Enterprise workspaces can use credits when flexible pricing is enabled.
- Using an API key always draws from separate pay-as-you-go API billing, not the ChatGPT plan allowance.
