## Plan comparison

| Plan | Price | ChatGPT access | Work and Codex | Published plan difference |
|---|---:|---|---|---|
| Free | US$0/month | ChatGPT chat access | Included for quick tasks | Entry-level access; feature and message allowances are plan-dependent. |
| Go | US$8/month | ChatGPT chat access | Included for lightweight tasks | Lower-cost paid individual plan. |
| Plus | US$20/month | ChatGPT paid individual plan | Included | Includes the GPT-5.6 family in Work and Codex, and eligible users can extend agentic usage with credits. |
| Pro — 5× | US$100/month | ChatGPT Pro | Included | 5× the Plus allowance for ChatGPT Work and Codex. |
| Pro — 20× | US$200/month | ChatGPT Pro | Included | 20× the Plus allowance for ChatGPT Work and Codex; unlimited ChatGPT Voice on desktop. Voice-started tasks still use the Work/Codex allowance. |
| Business | US$20/user/month annually, or US$25 monthly | Dedicated workspace | Included | Minimum two users; admin controls, SAML SSO, MFA, and no training on business data by default. |
| Edu / Enterprise | Contract pricing | Managed workspace | Included | Enterprise-grade controls and deployment terms. |

## Access boundaries

| Area | Published detail |
|---|---|
| ChatGPT app | Available on the web, desktop apps, and mobile apps. |
| Normal ChatGPT conversations | Have their own plan- and feature-specific usage limits. They are not the same as the Work/Codex allowance. |
| ChatGPT Work and Codex | Included with every ChatGPT plan and share one agentic usage allowance. See the [ChatGPT Work page](chatgpt-work.md) for the exact published ranges. |
| API | **Not included** with any ChatGPT subscription. API billing, usage limits, and credits are separate. See the [GPT API page](gpt.md). |
| Developer mode | Available on the web to Plus, Pro, Business, Enterprise, and Education accounts. |

## Important usage notes

- ChatGPT shows a reset time when a feature allowance is reached.
- A paid plan does not mean every ChatGPT model or tool is unlimited; individual models and features can have separate plan allowances.
- ChatGPT Work and Codex credits are separate from OpenAI API billing.
