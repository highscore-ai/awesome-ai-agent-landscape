# Open WebUI

[Official Open WebUI documentation](https://docs.openwebui.com/)

> Verified 25 August 2026.

| Deployment | Software cost | Other cost |
|---|---:|---|
| Self-hosted | Free to use | Your hardware, hosting, and chosen model/provider usage |
| Offline / local model | Free software | Local compute |
| Cloud-model gateway | Free software | Provider API charges |
| Enterprise support / white-labeling | Optional license | Contact Open WebUI |

Open WebUI can run locally and offline, and connects to Ollama plus OpenAI-compatible APIs. Its source code is public, but v0.6.6+ is **not OSI-approved open source**; it uses a branding-conditioned license. The map should therefore be read as “open/self-hosted ecosystem,” not a claim that every current release has an OSI-approved license.
