# OpenClaw

[Official OpenClaw site](https://openclaw.ai/)

> Verified 25 August 2026.

| Access path | Software cost | Ongoing cost |
|---|---:|---|
| Self-hosted on Mac, Windows, or Linux | Free software | Chosen hosted-model, gateway, or local-model infrastructure cost |
| Local models | Free software | Local compute and electricity |
| Hosted-model provider | Free software | Provider subscription or API billing |
| Messaging channels | Included software integration | Any channel/account cost applies |

OpenClaw is designed for a single operator and runs on the user’s own machine. It is not a vendor-hosted AI cloud; its state remains on the device. No official fixed subscription price is published because model and hosting choice are user-controlled.
