# OpenHands

[Official OpenHands pricing](https://www.openhands.dev/pricing)

> Verified 25 August 2026.

| Deployment | Price | Published access |
|---|---:|---|
| Local OpenHands | Free | Open-source local agent, web GUI, terminal UI, CLI, Git integrations, and model-agnostic configuration |
| OpenHands Cloud Individual | Free | Bring your own model key, or use provider access at cost |
| OpenHands Cloud paid usage | Pay-as-you-go | Hosted cloud and model-provider use |
| Self-hosted Cloud | 30-day trial + contact sales | Deploy in your own VPC; commercial terms after the trial |

OpenHands separates the open-source local agent from OpenHands Cloud. The `openhands-cloud` repository uses a Polyform Free Trial license and is not open source.
