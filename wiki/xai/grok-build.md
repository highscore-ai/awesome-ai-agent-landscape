Grok Build currently uses Grok 4.6. API-key use of `grok-build-0.1` costs US$1.00 input, US$0.20 cached input, and US$2.00 output per 1M tokens for short-context requests. It works in an interactive terminal UI, headless scripts/bots, and through the Agent Client Protocol.
