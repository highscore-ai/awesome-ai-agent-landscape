## What it is

Grok Bot is xAI’s move beyond chat and coding assistance into persistent work agents. Instead of only answering in a conversation, a Bot can work inside apps and websites, keep project context, follow a routine, and return when it needs approval.

xAI describes Bots as teammates: you assign an outcome, they carry the work through, and you review the sensitive steps.

## Why it belongs under “General Work Agent”

A general work agent should do more than help with a single prompt or one codebase. Grok Bot has the characteristics that place it in this fourth stage of the map:

- **Own computer:** each Bot has a separate execution environment.
- **Works across tools:** it can sign in to and use the same apps and websites a person uses.
- **Long-running execution:** Bots can keep working when a laptop is closed.
- **Routines:** a user can demonstrate a workflow once and ask the Bot to repeat it.
- **Parallel delegation:** multiple Bots can work on separate projects or hand work to one another.
- **Human approval:** the product is designed to bring the user back when approval is needed.

That makes it materially different from the Grok assistant, which is primarily chat-, search-, and creation-oriented, and from Grok Build, which is optimized for software work.

## What a Bot can do

| Work pattern | Example from xAI |
|---|---|
| Research and outbound | Research accounts, score contacts, draft outreach, and leave a review list |
| Chief-of-staff work | Read email, Slack, calendar, and notes, then return a prioritized briefing |
| Marketing operations | Pull campaign data and prepare a recommended budget reallocation |
| Personal operations | Track account health, recruiting tasks, expenses, or recurring work |
| Learned routines | Observe a completed workflow once, save it, and run it again later |
