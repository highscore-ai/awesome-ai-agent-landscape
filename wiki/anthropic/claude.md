# Claude

[Official Claude plans](https://www.anthropic.com/team)

> Prices in USD. Verified 25 August 2026.

| Plan | Price | Published capacity | API access |
|---|---:|---|---|
| Free | US$0 | Limited | Not included |
| Pro | US$17/month annual billing, or US$20 monthly | Standard | Not included |
| Max 5× | US$100/month | 5× Pro capacity per session | Not included |
| Max 20× | US$200/month | 20× Pro capacity per session | Not included |
| Team | Starts at US$20/seat/month | Team seat allowance | Separate billing |
| Enterprise | Contract pricing | Contract-specific | Separate billing |

Claude Pro and Max subscriptions include Claude Code and Claude Cowork. API billing is managed separately in Claude Console.
