# Claude Code

[Official Claude Code cost guide](https://docs.anthropic.com/en/docs/claude-code/costs)

> Verified 25 August 2026.

## Access

| Access method | Eligibility | Billing / limits |
|---|---|---|
| Claude subscription | Free, Pro, Max, Team, and Enterprise | Uses the plan allowance; Pro and Max limits are shown in `/status`. |
| Team / Enterprise seat | Standard or Premium seat | Per-seat allowance shared with Claude chat and Cowork; rolling 5-hour and weekly windows. |
| Claude API credits | Claude Console account | Standard Claude API token rates; can be used after opting in. |

- Pro: US$20/month, or US$200 annually.
- Max 5×: US$100/month. Max 20×: US$200/month.
- Exact Claude Code messages/tasks are not published as a fixed number because task size and model usage vary.
- To remain only within a Pro/Max plan, decline API credits and wait for the reset.
