## API account limits

| API tier | Monthly spend cap |
|---|---:|
| Start | US$500 |
| Build | US$1,000 |
| Scale | US$200,000 |
| Custom | Contract-specific |

API access is separate from Claude Free, Pro, Max, Team, and Enterprise subscriptions. When a spend cap is reached, API calls pause until the next calendar month unless the tier is raised.
